# Descargas de FlashRacs

Builds de prueba del juego.

- `FlashRacs-mac.zip`: Mac (Intel y Apple Silicon).
- `actualizar.sh`: descarga la ultima build, la instala en Aplicaciones y la abre.

Instalar o actualizar desde Terminal:

    curl -fsSL https://raw.githubusercontent.com/xNeku/FlashMapMaker/descargas/actualizar.sh | bash
